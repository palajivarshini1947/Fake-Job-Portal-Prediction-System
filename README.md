# Fake-Job-Portal-Prediction-System
Fake Job Portal Prediction System
📌 Project Description

The Fake Job Portal Prediction System is a web-based application that uses data mining and machine learning techniques to detect and classify fake job postings. The system helps job seekers identify fraudulent job offers and ensures a safer job-searching experience by predicting whether a job is genuine or fake.

🎯 Objective

To develop a web application that automatically detects fake job postings using data mining techniques and improves trust and security in online job portals.

🚀 Features
Fake job detection using machine learning algorithms
User registration and login system
Job posting and job browsing
Job authenticity prediction (Fake / Genuine)
Admin management system
OTP verification for security
Notification system
🧠 Modules
Admin Module
Manage users (approve/reject job providers and customers)
Monitor job postings
Manage notifications and system settings
Customer Module
Register and login
View job listings
Check job authenticity predictions
Apply for jobs
Manage profile
Job Provider Module
Register and login
Post and manage job listings
View applicants
Edit job details
Prediction Module
Uses data mining algorithms
Analyzes job description, company, salary, etc.
Classifies job as Fake or Genuine
🛠️ Technologies Used
Python
Django Framework
HTML, CSS, JavaScript, Bootstrap
MySQL Database
Machine Learning Algorithms (Naive Bayes, Decision Tree, SVM)
📊 Advantages
Reduces fake job scams
Improves trust in job portals
Automates job verification
Saves time for users
Provides secure job searching environment
📌 Conclusion

The Fake Job Portal Prediction System provides an efficient solution for detecting fake job postings using machine learning and data mining techniques. It improves security, reduces fraud, and enhances the reliability of online job portals.
